# Portfolio Website

A personal portfolio built with React and Tailwind CSS to showcase projects, skills, timeline highlights, and a contact form.

## Tech Stack

- React 18
- Create React App
- Tailwind CSS
- PostCSS + Autoprefixer

## Quick Start

### Prerequisites

- Node.js 18+
- Yarn 1.22+

### Run locally

1. Clone the repository:
   - `git clone https://github.com/ibrahimbaig334/portfolio.git`
2. Move into the project folder:
   - `cd portfolio`
3. Install dependencies:
   - `yarn install`
4. Start the development server:
   - `yarn start`

Open `http://localhost:3000` in your browser.

## Build for Production

- `yarn build`

Production files are generated in the `build/` directory.

## Notes

- The contact form uses Netlify Forms (`portfolio-contact`) and does not require frontend SMTP/API keys.
- This project currently uses Yarn as the package manager.
